# CodexDesk v0.1.0

CodexDesk 是使用 Codex App Server 的 Windows 桌面原型。

Windows 原生視窗，使用本機 Codex App Server。需要 Python、Pillow，以及已安裝且在 PATH 中的 Codex CLI。雙擊「啟動.bat」執行。若缺 Pillow，可執行 `python -m pip install Pillow`。

啟動後先檢查 Codex CLI 的 ChatGPT 登入狀態；如未登入，開啟瀏覽器登入。桌面版或瀏覽器登入不保證與 CLI 共用，必要時請登入一次。此程式不要求輸入 API key。

輸入問題，選擇附件或在輸入框按 Ctrl+V 貼上剪貼簿圖片，選擇輸出資料夾後送出。每次送出都是新的單次對話；程式在指定資料夾建立獨立任務資料夾，複製附件並提供 outputs 子資料夾。請透過「開啟輸出資料夾」查看輸出。

本原型不保證所有附件格式均可讀取或生成 AI 圖片，取決於 Codex 環境和可用工具。程式不提供檔案預覽、對話歷史及停止按鈕。執行命令或修改檔案可能顯示許可視窗；請確認內容再同意。使用量與登入帳戶方案限制有關。

存取權限可選擇唯讀、工作資料夾可寫入或完整電腦存取。唯讀模式不能產生檔案；完整存取的範圍涵蓋電腦其他位置，請審慎選用。實際權限也可能受到電腦與 Codex 設定限制。
